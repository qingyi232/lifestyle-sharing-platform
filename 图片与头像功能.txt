    生活方式分享与种草平台

----------------------------------------------------------------
一、本次更新解决了
----------------------------------------------------------------

  1. 发布笔记时：正文插图、封面图、「更多图片」上传失败或无法显示。
  2. 账号设置里：更换头像后，头像仍不显示或刷新后丢失。

  技术要点（了解即可）：
  · 上传接口需登录后使用；请先在系统内登录再发笔记、换头像。
  · 浏览器访问前端请使用 http://localhost:5173（开发模式），以便图片地址
    /uploads/... 能正确转发到后端。
  · 头像在「选择图片并成功上传」后会自动保存到账号，无需再单独点「保存修改」
    （昵称、简介等其它项仍要点「保存修改」）。

----------------------------------------------------------------
二、收到新版代码后应先做什么
----------------------------------------------------------------

  【1】用新版程序覆盖（或解压覆盖）原项目文件夹，保持目录结构不变，至少包含：
        backend\
        frontend\
        database\

  【2】若 MySQL 密码不是 root，请检查并修改：
        backend\src\main\resources\application.yml
        中的 username、password，与本地 MySQL 一致。

  【3】确认 MySQL 服务已启动（一般开机自启）。

----------------------------------------------------------------
三、后端：必须重新编译后再运行
----------------------------------------------------------------

  方式 A（命令行，在项目 backend 目录下）：

    mvn clean package -DskipTests

    编译成功后启动：

    java -jar target\lifestyle-platform-1.0.0.jar

  方式 B（IntelliJ IDEA）：

    1. 用 IDEA 打开项目根目录。
    2. 菜单 Build → Rebuild Project（或先 Maven → Reload，再执行 package）。
    3. 运行主类 LifestylePlatformApplication（右上角绿色运行按钮）。

  ★ 后端窗口请保持运行，不要关闭。

----------------------------------------------------------------
四、前端：安装依赖（如有需要）并启动
----------------------------------------------------------------

  1. 打开新的命令提示符或 PowerShell，进入前端目录，例如：

     cd D:\你的路径\生活方式分享与种草平台\frontend

  2. 若从未安装依赖或依赖有更新，执行一次：

     npm install

  3. 启动开发服务：

     npm run dev

  4. 浏览器访问（请使用此地址，不要直接打开 dist 里的 html 文件测上传）：

     http://localhost:5173

  ★ 前端窗口也请保持运行。

----------------------------------------------------------------
五、推荐自测步骤（按顺序做）
----------------------------------------------------------------

  1. 使用测试账号登录（密码见《部署运行文档.txt》第六节，如 admin / 123456）。

  2. 测头像：
     · 进入「账号设置」→ 点击「更换头像」→ 选一张 jpg/png 等常见图片。
     · 成功时应提示「头像已更新」，页面与顶部导航栏头像应刷新为新图。

  3. 测发笔记图片：
     · 进入「发布笔记」或编辑笔记。
     · 分别测试：封面上传、正文里工具栏「插入图片」、下方「更多图片」上传。
     · 保存或发布后，在列表与详情页应能看到对应图片。

  4. 若任一步失败：
     · 确认已登录（未登录时上传会失败）。
     · 按第六节简单排查。

----------------------------------------------------------------
六、常见问题
----------------------------------------------------------------

  【问题】上传提示失败或未登录
  【处理】先退出再重新登录；确认后端已启动且未报错。

  【问题】图片地址是 /uploads/... 但页面裂图
  【处理】确认访问的是 http://localhost:5173，且后端在 8080 运行；
          不要只用前端静态文件打开页面而不走后端。

  【问题】修改了后端代码但行为没变
  【处理】必须重新执行 mvn package 或用 IDEA 重新编译后再启动后端。

  【问题】使用 npm run preview 预览打包结果
  【处理】新版已配置 preview 代理；仍须保证后端 8080 已启动。
