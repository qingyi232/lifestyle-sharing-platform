★★★ 重要提示（之前部署过旧版本的必看）★★★

如果你之前部署过旧版本，必须按以下步骤清除旧数据，否则新版本无法正常运行：

【第1步】删除旧的数据库
  1. 右键"开始菜单" → 选择"命令提示符(管理员)"或"终端(管理员)"
  2. 先确保 MySQL 服务已启动，输入：
       net start mysql80
     （如果提示"已经启动"就继续下一步）
  3. 登录 MySQL，输入：
       mysql -u root -p
     然后输入你的 MySQL 密码（默认为 root，如果报错就是123456或者试试其他常用密码），按回车
  4. 进入 mysql> 提示符后，输入以下命令删除旧数据库：
       DROP DATABASE IF EXISTS lifestyle_platform;
     看到 "Query OK" 表示删除成功
  5. 输入 exit 退出 MySQL

【第2步】删除旧的项目文件夹
  1. 打开文件资源管理器，找到之前解压的旧项目文件夹
     例如：D:\某某\生活方式分享与种草平台
  2. 右键该文件夹 → 点"删除"（或选中后按 Delete 键）
  3. 清空回收站（可选）

【第3步】解压新的压缩包
  1. 找到新收到的压缩包 "生活方式分享与种草平台 (2).zip"
  2. 右键 → "解压到当前文件夹" 或 "解压到..."
  3. 解压到你想要的目录，例如：D:\生活方式分享与种草平台

完成以上3步后，继续按本文档从"三、数据库配置"开始操作即可。

如果是全新安装（之前没部署过），直接从下面的"一、环境准备"开始即可。

一、环境准备（软件安装）
================================================================

本项目需要以下4个软件，请按顺序安装。
如果之前已经安装过，可以跳过对应步骤（用验证命令确认即可）。

【1】JDK 17（Java开发工具包）
--------------------------------------------------------------
作用：运行后端Spring Boot项目

下载地址：
  Oracle JDK 17: https://www.oracle.com/java/technologies/javase/jdk17-archive-downloads.html
  或 OpenJDK 17: https://adoptium.net/zh-CN/temurin/releases/?version=17

安装步骤（Windows）：
  1. 下载 .msi 或 .exe 安装包（选择 Windows x64）
  2. 双击运行安装程序，一路点"下一步"即可
  3. 安装完成后，配置环境变量：
     a. 右键"此电脑" → "属性" → "高级系统设置" → "环境变量"
     b. 在"系统变量"中点"新建"：
        变量名：JAVA_HOME
        变量值：C:\Program Files\Java\jdk-17（你的实际安装路径）
     c. 找到"系统变量"中的 Path，双击编辑，点"新建"，添加：
        %JAVA_HOME%\bin
     d. 点确定保存
  4. 验证安装：
     打开命令提示符（Win+R 输入 cmd 回车），输入：
     java -version
     应显示类似：openjdk version "17" ...

【2】MySQL 8.0（数据库）
--------------------------------------------------------------
作用：存储系统所有数据

下载地址：
  https://dev.mysql.com/downloads/installer/
  选择 "MySQL Installer for Windows"

安装步骤：
  1. 下载 mysql-installer-community-8.0.xx.msi
  2. 双击运行，选择 "Developer Default" 或 "Server only"
  3. 安装过程中会要求设置 root 密码：
     ★★★ 请设置为：root（与项目默认配置一致）★★★
     如果设置了其他密码，后面需要修改配置文件
  4. 其他选项保持默认，一路下一步完成安装
  5. 验证安装：
     打开命令提示符，输入：
     mysql -u root -p
     输入密码后能进入 mysql> 提示符即表示成功
     输入 exit 退出

  如果 mysql 命令找不到，需要将 MySQL 的 bin 目录加入 Path：
     通常路径为：C:\Program Files\MySQL\MySQL Server 8.0\bin
     添加方法同上面 JAVA_HOME 的 Path 配置

【3】Apache Maven 3.6+（后端构建工具）
--------------------------------------------------------------
作用：编译打包后端Java项目

下载地址：
  https://maven.apache.org/download.cgi
  下载 "Binary zip archive"，如 apache-maven-3.9.6-bin.zip

安装步骤：
  1. 将下载的 zip 解压到一个目录，例如：C:\apache-maven-3.9.6
  2. 配置环境变量：
     a. 新建系统变量：
        变量名：MAVEN_HOME
        变量值：C:\apache-maven-3.9.6
     b. 编辑 Path，添加：
        %MAVEN_HOME%\bin
  3. 验证安装：
     打开新的命令提示符，输入：
     mvn -version
     应显示 Maven 版本信息

  ★ Maven 镜像加速（重要，否则下载依赖很慢）：
     找到 Maven 安装目录下的 conf\settings.xml 文件
     用记事本打开，找到 <mirrors> 标签，在里面添加：

     <mirror>
       <id>aliyun</id>
       <mirrorOf>central</mirrorOf>
       <name>阿里云Maven镜像</name>
       <url>https://maven.aliyun.com/repository/central</url>
     </mirror>

     保存文件。

【4】Node.js 18+（前端运行环境）
--------------------------------------------------------------
作用：运行前端Vue项目

下载地址：
  https://nodejs.org/zh-cn
  选择 LTS（长期支持版），如 18.x 或 20.x

安装步骤：
  1. 下载 .msi 安装包
  2. 双击运行，一路下一步（默认会自动配置 Path）
  3. 验证安装：
     打开命令提示符，输入：
     node -v      （应显示 v18.x.x 或更高）
     npm -v       （应显示 9.x.x 或更高）

  ★ npm 镜像加速（重要，否则安装依赖很慢）：
     在命令提示符中执行：
     npm config set registry https://registry.npmmirror.com
     验证：npm config get registry
     应显示：https://registry.npmmirror.com

三、数据库配置
================================================================

★★★ 如果之前部署过旧版本，必须先删除旧数据库 ★★★

【步骤1】打开命令提示符（以管理员身份运行），登录MySQL：
  mysql -u root -p
  （输入你的MySQL root密码，默认为 root）

【步骤2】如果之前部署过旧版本，先删除旧数据库：
  在 mysql> 提示符下执行：
    DROP DATABASE IF EXISTS lifestyle_platform;

【步骤3】执行数据库初始化脚本：
  在 mysql> 提示符下执行（注意替换为你的实际路径）：
    source D:/生活方式分享与种草平台/database/init.sql;
    （注意：路径中使用正斜杠 / ，不要用反斜杠 \）

  如果 source 命令报错，可以用方法二：
    直接用记事本打开 database\init.sql 文件，
    复制全部内容，粘贴到 mysql> 提示符中执行

【步骤4】验证数据库创建成功：
  在 mysql> 提示符下执行：
    USE lifestyle_platform;
    SHOW TABLES;

  应该看到以下10张表：
    categories, comments, favorites, follows, likes,
    note_tags, notes, notifications, tags, users

  验证完成后输入 exit 退出MySQL。

【步骤5】如果你的MySQL密码不是 root，需要修改后端配置：
  用记事本打开文件：
    D:\生活方式分享与种草平台\backend\src\main\resources\application.yml

  找到这两行：
    username: root
    password: root

  将 password 后面的 root 改为你的实际MySQL密码，保存文件。

  ★ 修改密码后需要重新编译后端（见第四步的步骤2）★


================================================================
四、后端部署运行
================================================================

【步骤1】打开命令提示符，进入后端目录：
  cd D:\生活方式分享与种草平台\backend

【步骤2】编译打包项目：
  mvn clean package -DskipTests

  首次运行会下载大量依赖包，可能需要5-15分钟（取决于网速）。
  如果配置了阿里云镜像会快很多。

  看到以下输出表示成功：
    [INFO] BUILD SUCCESS
    [INFO] Total time: xx s

  如果报错，请查看文档末尾"常见问题"部分。

【步骤3】启动后端服务：
  java -jar target/lifestyle-platform-1.0.0.jar

  看到以下输出表示启动成功：
    Started LifestylePlatformApplication in x.xxx seconds

  ★ 后端启动后会自动初始化示例数据（6个用户、16篇笔记、评论等）
  ★ 后端运行在 http://localhost:8080
  ★ 不要关闭这个命令提示符窗口！后端需要一直运行

【步骤4】验证后端是否正常：
  打开浏览器，访问：
    http://localhost:8080/api/categories

  如果看到 JSON 格式的分类数据，说明后端运行正常。

五、前端部署运行

★ 请另开一个新的命令提示符窗口（不要关闭后端窗口）

八、每次开机后如何启动（日常使用）
================================================================

电脑重启后，项目不会自动运行，需要手动启动。
按以下步骤操作即可：

────────────────────────────────────────
方式一：使用 IDEA 启动（推荐，如果安装了 IDEA）
────────────────────────────────────────

【第1步】确保 MySQL 服务已启动
  - 右键"开始菜单" → 选择"命令提示符(管理员)"或"终端(管理员)"
  - 输入：net start mysql80
  - 如果提示"已经启动"就说明正常
  - 如果提示"服务名无效"，尝试：net start mysql
  - ★ 这一步必须用管理员权限的命令提示符 ★

【第2步】用 IDEA 打开项目
  - 打开 IntelliJ IDEA
  - 选择"打开"→ 找到项目文件夹（如 D:\生活方式分享与种草平台）→ 打开
  - 等待 IDEA 加载完成（右下角进度条走完）

【第3步】启动后端
  - 在 IDEA 右上角找到运行配置，应显示 "LifestylePlatformApplication"
  - 点击旁边的 绿色三角形 ▶ 按钮
  - 等待 IDEA 下方控制台出现：
    "Started LifestylePlatformApplication in x.xxx seconds"
    就说明后端启动成功了！
  - ★ 不要关闭 IDEA，后端需要一直运行

【第4步】启动前端
  - 在 IDEA 下方找到 "终端"（Terminal）面板，点击打开
  - 如果终端面板没有显示，按快捷键 Alt+F12 打开
  - 在终端中依次执行以下两条命令：
    cd frontend
    npm run dev
  - 看到以下输出表示前端启动成功：
    VITE v5.x.x  ready in xxx ms
    ➜  Local:   http://localhost:5173/
  - ★ 不要关闭这个终端

【第5步】打开浏览器访问系统
  - 打开 Chrome 或 Edge 浏览器
  - 地址栏输入：http://localhost:5173
  - 回车即可看到系统首页

【第6步】如需关闭系统
  - 前端：在 IDEA 终端中按 Ctrl+C
  - 后端：点击 IDEA 左下角控制台的 红色方块 ■ 停止按钮
  - 然后可以关闭 IDEA

================================================================
九、常见问题与解决方案
================================================================

【问题1】net start mysql80 提示"发生系统错误 5，拒绝访问"
  原因：没有用管理员权限运行命令提示符
  解决：
    关闭当前窗口，右键"开始菜单" → 选择"命令提示符(管理员)"
    或搜索 cmd → 右键 → "以管理员身份运行"
    然后再执行 net start mysql80

【问题2】net start mysql80 提示"服务名无效"
  原因：MySQL 服务名可能不是 mysql80
  解决：
    执行以下命令查找实际服务名：
      sc query type= service state= all | findstr /i mysql
    找到服务名后用 net start 服务名 启动

【问题3】mvn 命令找不到
  原因：Maven 未安装或环境变量未配置
  解决：
    1. 确认 Maven 已解压到指定目录
    2. 确认 MAVEN_HOME 和 Path 已正确配置
    3. 关闭并重新打开命令提示符

【问题4】java 命令找不到
  原因：JDK 未安装或环境变量未配置
  解决：
    1. 确认 JDK 17 已安装
    2. 确认 JAVA_HOME 和 Path 已正确配置
    3. 关闭并重新打开命令提示符

【问题5】Maven 编译报错 "Unsupported class file major version"
  原因：JDK 版本不匹配，项目需要 JDK 17
  解决：
    1. 确认安装的是 JDK 17（不是 JDK 8 或 JDK 21）
    2. 确认 JAVA_HOME 指向 JDK 17 的安装目录
    3. 在命令提示符中执行 java -version 确认版本

【问题6】后端启动报错 "Port 8080 already in use"
  原因：8080 端口被其他程序占用
  解决：
    方法一：关闭占用 8080 端口的程序
      在命令提示符中执行：
        netstat -ano | findstr :8080
      找到 PID（最后一列数字），然后：
        taskkill /PID 对应PID /F

    方法二：修改后端端口
      编辑 backend\src\main\resources\application.yml
      将 port: 8080 改为其他端口如 port: 8081
      同时修改 frontend\vite.config.js 中的 proxy target 为对应端口
      修改后需要重新编译后端：mvn clean package -DskipTests

【问题7】后端启动报错 "Access denied for user 'root'"
  原因：MySQL 密码不正确
  解决：
    编辑 backend\src\main\resources\application.yml
    将 password: root 改为你的实际 MySQL 密码
    保存后重新编译：mvn clean package -DskipTests
    然后重新启动：java -jar target/lifestyle-platform-1.0.0.jar

【问题8】后端启动报错 "Unknown database 'lifestyle_platform'"
  原因：数据库未创建
  解决：按照"三、数据库配置"步骤执行 init.sql 脚本

【问题9】后端启动报错 "Communications link failure" 或 "数据库无法连接"
  原因：MySQL 服务未启动
  解决：
    1. 以管理员身份打开命令提示符
    2. 执行：net start mysql80
    3. 如果提示服务名无效，执行：
       sc query type= service state= all | findstr /i mysql
       找到正确的服务名后启动

【问题10】npm install 报错或很慢
  原因：npm 默认源在国外，下载慢
  解决：
    1. 设置淘宝镜像：npm config set registry https://registry.npmmirror.com
    2. 删除 node_modules 文件夹后重新执行 npm install
    3. 如果仍然报错，尝试：npm install --legacy-peer-deps

【问题11】前端页面打开空白或显示"数据库无法连接"
  原因：后端未启动或数据库连接失败
  解决：
    1. 确认 MySQL 服务已启动（net start mysql80）
    2. 确认后端正在运行（命令提示符窗口显示 "Started LifestylePlatformApplication"）
    3. 浏览器访问 http://localhost:8080/api/categories 确认后端正常
    4. 如果后端报错，检查数据库密码是否正确

【问题12】前端页面显示但数据为空
  原因：后端未启动或数据库连接失败
  解决：
    1. 确认后端命令提示符窗口显示 "Started LifestylePlatformApplication"
    2. 浏览器访问 http://localhost:8080/api/categories 确认后端正常
    3. 检查后端控制台是否有报错信息

【问题13】图片上传后无法显示
  原因：上传目录权限问题
  解决：
    上传的图片存储在 backend 目录下的 uploads 文件夹中
    确保该目录有读写权限（Windows 下通常不会有此问题）

【问题14】Maven 下载依赖超时
  原因：网络问题或未配置镜像
  解决：
    1. 确认已在 Maven 的 settings.xml 中配置阿里云镜像
    2. 重新执行 mvn clean package -DskipTests
    3. 如果仍然超时，检查网络连接

【问题15】电脑重启后系统无法访问
  原因：重启后后端和前端服务都停止了
  解决：按照"八、每次开机后如何启动"的步骤重新启动即可
  ★ 特别注意：第一步一定要先启动 MySQL 服务（需要管理员权限）
