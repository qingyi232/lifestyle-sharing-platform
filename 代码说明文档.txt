一、项目概述
================================================================

项目名称：生活方式分享与种草平台
项目类型：前后端分离的Web应用系统

技术架构：
  后端：Spring Boot 2.7.18 + MyBatis-Plus 3.5.3.1 + MySQL 8
  前端：Vue 3 + Vite 5 + Element Plus + ECharts
  认证：JWT（JSON Web Token）无状态认证
  接口：RESTful API 风格
  构建：Maven（后端）+ npm（前端）

系统功能：
  用户端 —— 注册登录、浏览笔记、发布笔记（富文本+图片）、
           点赞收藏评论、关注用户、搜索筛选、个人中心管理
  管理端 —— 用户管理、内容审核、分类管理、数据统计仪表盘

四、数据库设计
================================================================

数据库名：lifestyle_platform
字符集：utf8mb4
排序规则：utf8mb4_general_ci

共10张数据表，关系如下：

【1】users - 用户表
  字段名            类型              说明
  ─────────────────────────────────────────────
  id               BIGINT PK AI      用户ID
  username         VARCHAR(50) UNI   用户名（唯一，登录用）
  email            VARCHAR(100)      邮箱（可选）
  phone            VARCHAR(20)       手机号（可选）
  password         VARCHAR(255)      密码（BCrypt加密存储）
  nickname         VARCHAR(50)       昵称（显示用）
  avatar           VARCHAR(500)      头像URL
  bio              TEXT              个人简介
  role             VARCHAR(20)       角色：user/admin
  status           INT DEFAULT 1     状态：0=禁用 1=正常
  followers_count  INT DEFAULT 0     粉丝数
  following_count  INT DEFAULT 0     关注数
  notes_count      INT DEFAULT 0     笔记数
  created_at       DATETIME          注册时间
  updated_at       DATETIME          更新时间

【2】categories - 分类表
  字段名            类型              说明
  ─────────────────────────────────────────────
  id               BIGINT PK AI      分类ID
  name             VARCHAR(50) UNI   分类名称
  icon             VARCHAR(50)       图标标识
  sort_order       INT DEFAULT 0     排序序号

【3】notes - 笔记表
  字段名            类型              说明
  ─────────────────────────────────────────────
  id               BIGINT PK AI      笔记ID
  user_id          BIGINT FK         作者用户ID
  title            VARCHAR(200)      标题
  content          TEXT              正文内容（HTML富文本）
  cover_image      VARCHAR(500)      封面图URL
  images           TEXT              附加图片URL（JSON数组）
  category_id      BIGINT FK         所属分类ID
  status           INT DEFAULT 0     状态：0=待审核 1=已发布 2=已驳回
  reject_reason    VARCHAR(500)      驳回原因
  view_count       INT DEFAULT 0     浏览量
  like_count       INT DEFAULT 0     点赞数
  comment_count    INT DEFAULT 0     评论数
  favorite_count   INT DEFAULT 0     收藏数
  created_at       DATETIME          创建时间
  updated_at       DATETIME          更新时间

  外键：user_id → users(id) ON DELETE CASCADE
  外键：category_id → categories(id) ON DELETE SET NULL

【4】tags - 标签表
  字段名            类型              说明
  ─────────────────────────────────────────────
  id               BIGINT PK AI      标签ID
  name             VARCHAR(50) UNI   标签名称

【5】note_tags - 笔记标签关联表（多对多）
  字段名            类型              说明
  ─────────────────────────────────────────────
  note_id          BIGINT FK         笔记ID
  tag_id           BIGINT FK         标签ID
  PRIMARY KEY (note_id, tag_id)

  外键：note_id → notes(id) ON DELETE CASCADE
  外键：tag_id → tags(id) ON DELETE CASCADE

【6】comments - 评论表（支持嵌套回复）
  字段名            类型              说明
  ─────────────────────────────────────────────
  id               BIGINT PK AI      评论ID
  note_id          BIGINT FK         所属笔记ID
  user_id          BIGINT FK         评论者用户ID
  parent_id        BIGINT            父评论ID（NULL=顶级评论）
  content          TEXT              评论内容
  created_at       DATETIME          评论时间

  外键：note_id → notes(id) ON DELETE CASCADE
  外键：user_id → users(id) ON DELETE CASCADE

【7】likes - 点赞表
  字段名            类型              说明
  ─────────────────────────────────────────────
  id               BIGINT PK AI      记录ID
  user_id          BIGINT FK         点赞用户ID
  note_id          BIGINT FK         被赞笔记ID
  created_at       DATETIME          点赞时间
  UNIQUE (user_id, note_id)          防止重复点赞

【8】favorites - 收藏表
  字段名            类型              说明
  ─────────────────────────────────────────────
  id               BIGINT PK AI      记录ID
  user_id          BIGINT FK         收藏用户ID
  note_id          BIGINT FK         被收藏笔记ID
  created_at       DATETIME          收藏时间
  UNIQUE (user_id, note_id)          防止重复收藏

【9】follows - 关注表
  字段名            类型              说明
  ─────────────────────────────────────────────
  id               BIGINT PK AI      记录ID
  follower_id      BIGINT FK         关注者用户ID
  following_id     BIGINT FK         被关注者用户ID

【10】notifications - 通知表

五、后端架构说明
================================================================

【分层架构】

  HTTP请求 → Controller（控制器层）→ Service（业务逻辑层）→ Mapper（数据访问层）→ MySQL数据库

  Controller：接收HTTP请求，参数校验，调用Service，返回Result<T>
  Service：核心业务逻辑处理，事务管理
  Mapper：继承MyBatis-Plus的BaseMapper，自动生成CRUD SQL
  Entity：与数据库表一一对应的Java实体类
  DTO：数据传输对象，用于接收请求参数或返回视图数据

【统一响应格式 Result<T>】

  所有API返回统一JSON格式：
  {
    "code": 200,          // 状态码：200成功，400参数错误，401未认证，403禁止，500服务器错误
    "message": "操作成功", // 提示信息
    "data": { ... }       // 返回数据（可选）
  }

  Result.java 提供静态方法：
    Result.success(data)           → code=200
    Result.success(message, data)  → code=200
    Result.error(message)          → code=400
    Result.error(code, message)    → 自定义code

【JWT认证流程】

  1. 用户登录 → AuthController.login() → 验证用户名密码
  2. 验证通过 → JwtUtil.generateToken(userId) → 生成JWT令牌（有效期7天）
  3. 返回token给前端 → 前端存入localStorage
  4. 后续请求 → 前端在请求头添加 Authorization: Bearer <token>
  5. JwtInterceptor拦截请求 → 解析token → 将userId存入request属性
  6. Controller通过 request.getAttribute("userId") 获取当前用户ID

  JwtInterceptor 拦截规则：
    拦截路径：/api/**
    排除路径：/api/auth/**（登录注册）、/api/upload/**（文件上传）
    可选认证（GET请求）：
      /api/notes, /api/notes/{id}, /api/notes/hot
      /api/categories
      /api/comments/note/{noteId}
      /api/users/{id}, /api/users/{id}/notes
      /api/users/{id}/followers, /api/users/{id}/following

【DataInitializer 数据初始化器】

  实现 CommandLineRunner 接口，在Spring Boot启动后自动执行。
  检查users表是否为空：
    - 如果为空：初始化6个用户、8个分类、20+标签、16篇笔记、
      评论、点赞、收藏、关注关系、通知等完整示例数据
    - 如果不为空：跳过初始化，打印"数据库已有数据，跳过初始化"

  所有示例图片使用 Unsplash 在线图片URL，无需本地图片文件。

【密码加密】

  使用 Spring Security 的 BCryptPasswordEncoder 进行密码加密。
  注册时：明文密码 → BCrypt加密 → 存入数据库
  登录时：输入密码 → BCrypt.matches(输入, 数据库密文) → 验证

六、后端API接口清单
================================================================

【认证模块 AuthController】
  POST /api/auth/register        用户注册
    请求体：{ username, password, nickname, email?, phone? }
    返回：{ code:200, data:{ token, user } }

  POST /api/auth/login           用户登录
    请求体：{ username, password }
    返回：{ code:200, data:{ token, user } }

【用户模块 UserController】
  GET  /api/users/profile        获取当前登录用户资料（需认证）
  PUT  /api/users/profile        更新用户资料（需认证）
    请求体：{ nickname?, avatar?, bio?, email?, phone? }
  PUT  /api/users/password       修改密码（需认证）
    请求体：{ oldPassword, newPassword }
  DELETE /api/users/account      注销账号（需认证，级联删除所有关联数据）

  GET  /api/users/{id}           获取用户公开信息
  GET  /api/users/{id}/notes     获取指定用户的笔记列表
  GET  /api/users/{id}/followers 获取粉丝列表
  GET  /api/users/{id}/following 获取关注列表

【笔记模块 NoteController】
  GET  /api/notes                笔记列表（分页+搜索+分类筛选+排序）
    参数：page, size, keyword?, categoryId?, orderBy(latest/hot)
  GET  /api/notes/{id}           笔记详情（自动增加浏览量）
  POST /api/notes                创建笔记（需认证）
    请求体：{ title, content, coverImage?, images?, categoryId, tagList? }
  PUT  /api/notes/{id}           更新笔记（需认证，仅作者可操作）
  DELETE /api/notes/{id}         删除笔记（需认证，仅作者可操作）

  GET  /api/notes/my             我的笔记列表（需认证）
  GET  /api/notes/favorites      我的收藏列表（需认证）
  GET  /api/notes/following      关注用户的笔记（需认证）
  GET  /api/notes/hot            热门笔记推荐

【评论模块 CommentController】
  GET  /api/comments/note/{noteId}  获取笔记的评论列表
  POST /api/comments                发表评论（需认证）
    请求体：{ noteId, content, parentId? }
  DELETE /api/comments/{id}         删除评论（需认证，仅评论者可操作）

【互动模块 InteractionController】
  POST /api/interactions/like/{noteId}     点赞/取消点赞（需认证，切换式）
    返回：{ liked: true/false }
  POST /api/interactions/favorite/{noteId} 收藏/取消收藏（需认证，切换式）
    返回：{ favorited: true/false }
  POST /api/interactions/follow/{userId}   关注/取消关注（需认证，切换式）
    返回：{ followed: true/false }
  GET  /api/interactions/status/{noteId}   获取当前用户对笔记的互动状态
    返回：{ liked, favorited }
  GET  /api/interactions/follow-status/{userId} 获取关注状态
    返回：{ followed }

【通知模块 NotificationController】
  GET  /api/notifications              获取通知列表（需认证，分页）
  PUT  /api/notifications/{id}/read    标记单条通知已读
  PUT  /api/notifications/read-all     全部标记已读
  GET  /api/notifications/unread-count 获取未读通知数量

【分类模块 CategoryController】
  GET  /api/categories             获取所有分类列表（公开接口）

【文件上传 FileUploadController】
  POST /api/upload                 上传文件（图片）
    请求体：multipart/form-data, 字段名 file
    返回：{ code:200, data: "/uploads/xxx.jpg" }
    文件存储在 backend/uploads/ 目录下

【管理后台 AdminController】（需管理员权限）
  GET  /api/admin/stats            获取统计数据（总用户/笔记/评论/日活/趋势）
  GET  /api/admin/users            用户列表（分页+搜索）
  PUT  /api/admin/users/{id}/status       修改用户状态（启用/禁用）
  PUT  /api/admin/users/{id}/reset-password 重置用户密码为123456
  GET  /api/admin/notes            待审核笔记列表
  GET  /api/admin/notes/all        全部笔记列表
  PUT  /api/admin/notes/{id}/approve      审核通过笔记
  PUT  /api/admin/notes/{id}/reject       驳回笔记（附驳回原因）
  POST /api/admin/categories       添加分类
  PUT  /api/admin/categories/{id}  修改分类
  DELETE /api/admin/categories/{id} 删除分类

七、前端架构说明
================================================================

【Vue 3 Composition API】

  所有组件使用 <script setup> 语法，这是Vue 3推荐的写法。
  特点：更简洁、更好的TypeScript支持、更好的逻辑复用。

【Pinia 状态管理】

  stores/user.js 管理全局用户状态：
    - token：JWT令牌，持久化到localStorage
    - userInfo：当前用户信息对象
    - isLoggedIn：计算属性，判断是否已登录
    - isAdmin：计算属性，判断是否为管理员
    - login(data)：保存token和用户信息
    - logout()：清除token和用户信息
    - fetchProfile()：从后端获取最新用户资料

【Axios 请求封装】

  api/request.js 创建Axios实例：
    - baseURL: '/api'（通过Vite代理转发到后端8080端口）
    - 请求拦截器：自动在请求头添加 Authorization: Bearer <token>
    - 响应拦截器：
      * 正常响应：直接返回 response.data
      * 401错误：清除token，跳转到登录页
      * 其他错误：显示Element Plus错误提示

【Vue Router 路由配置】

  router/index.js 定义所有路由：
    公开路由：首页、登录、注册、笔记详情、搜索、用户主页
    需认证路由（meta.requiresAuth = true）：
      笔记编辑、个人中心、我的笔记、我的收藏、关注列表、
      设置、通知
    管理路由（meta.requiresAdmin = true）：
      /admin 及其子路由（仪表盘、用户管理、内容审核、分类管理）

  导航守卫：
    - requiresAuth 路由：未登录则跳转到 /login
    - requiresAdmin 路由：非管理员则跳转到 /

【Vite 开发代理】

  vite.config.js 配置：
    /api 开头的请求 → 代理到 http://localhost:8080
    自动去除 /api 前缀（rewrite）

【Element Plus UI组件库】

  全局注册，提供：
    - 表单组件：ElInput, ElSelect, ElDatePicker 等
    - 数据展示：ElTable, ElPagination, ElTag 等
    - 反馈组件：ElMessage, ElMessageBox, ElNotification 等
    - 布局组件：ElContainer, ElMenu, ElCard 等
    - 图标：@element-plus/icons-vue 全局注册

【wangeditor 富文本编辑器】

  用于笔记编辑页面（NoteEdit.vue），支持：
    - 文字格式化（加粗、斜体、标题等）
    - 图片插入（支持上传到后端）
    - 链接插入
    - 列表、引用等

【ECharts 图表】

  用于管理后台仪表盘（Dashboard.vue），展示：
    - 用户增长趋势折线图（近7天）
    - 笔记发布趋势折线图（近7天）
    - 数据随真实数据库数据动态变化
